This project is a REST API built with Python, Flask, and SQLite.

Book Model
The Book model contains:

id
book_name
author
publisher

CRUD Operations
Create
POST /books

Read
GET /books

Update
PUT /books/

Delete
DELETE /books/

Technologies Used
Python
Flask
Flask-SQLAlchemy
SQLite
Thunder Client

Running the Project
Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Access:

http://127.0.0.1:5000/books
